# Meccanica Quantistica: appunti

Appunti in LaTeX del corso di **Fisica Quantistica** tenuto dal Prof. Camillo Imbimbo
all'Università di Genova (a.a. [2024/2025]). 

🚧 Potrebbe arrivare anche una versione tradotta in inglese.

📄 **[Scarica il PDF](https://github.com/GioeleCesarini/appunti_MeccanicaQuantistica/releases/latest/download/rootMQ.pdf)**

## Contenuti

1. [La crisi della fisica classica]
2. [La vecchia teoria quantistica]
3. [Il formalismo della meccanica quantistica]
4. [Teoria delle rappresentazioni]
5. [Equazione di Schrodinger per sistemi unidimensionali]
6. [Evoluzione temporale]
7. [Teoria del momento angolare]
8. [Sistemi di particelle identiche]
9. [Pillole: brevi consigli o nozioni condensate]

## Fonti

- Lezioni del Prof. Camillo Imbimbo, Università di Genova
- Appunti di [Filippo Teramo]
- L. E. Picasso, *Lezioni di Meccanica Quantistica*, Edizioni ETS

## Avvertenza

Questi sono appunti personali, non revisionati dal docente: possono contenere errori
o imprecisioni. Se ne trovi uno proponi una correzione con una pull request.

## Compilare dai sorgenti

Serve una distribuzione LaTeX (TeX Live o MacTeX). Dalla cartella del progetto:

    latexmk -pdf rootMQ.tex

Il PDF viene comunque compilato automaticamente a ogni modifica tramite GitHub Actions.
